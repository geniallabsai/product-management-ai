# Criar repositório privado no GitHub

Quando quiser subir: gh auth login -h github.com; gh repo create geniallabsai/product-management-ai --private --source . --remote origin --push.

## Checklist prático

- Qual decisão precisa ser tomada?
- Quais evidências existem?
- Quais hipóteses ainda precisam ser testadas?
- Qual artefato será criado?
- Quem é dono do próximo passo?
