# Sistema de skills

Cada skill é um agente especializado. Pode ser usada sozinha copiando o arquivo Markdown ou pelo CLI com pm-ai skill <id>.

## Checklist prático

- Qual decisão precisa ser tomada?
- Quais evidências existem?
- Quais hipóteses ainda precisam ser testadas?
- Qual artefato será criado?
- Quem é dono do próximo passo?
