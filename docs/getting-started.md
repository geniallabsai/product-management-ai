# Começando do zero

Guia para sair de uma ideia e chegar a um MVP validável. Preencha o brief, rode diagnóstico, faça discovery, reduza escopo e valide antes de construir pesado.

## Checklist prático

- Qual decisão precisa ser tomada?
- Quais evidências existem?
- Quais hipóteses ainda precisam ser testadas?
- Qual artefato será criado?
- Quem é dono do próximo passo?
