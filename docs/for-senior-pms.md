# Guia para PMs experientes

Use o repositório como acelerador operacional: discovery, PRD, priorização, métricas, fatiamento técnico, roadmap e rituais. A saída não substitui julgamento de produto.

## Checklist prático

- Qual decisão precisa ser tomada?
- Quais evidências existem?
- Quais hipóteses ainda precisam ser testadas?
- Qual artefato será criado?
- Quem é dono do próximo passo?
