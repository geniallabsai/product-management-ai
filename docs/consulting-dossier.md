# Dossiê Startup AI OS

A aba Dossiê transforma o Startup AI OS em uma ferramenta de consultoria para empresas novas, empresas de tecnologia existentes e empresas tradicionais em transformação digital.

## Entradas

- Ideia ou contexto da empresa.
- Tipo de empresa.
- Objetivos.
- Restrições.
- Evidências técnicas, incluindo código local/repositório.

## Saídas

- Nota de maturidade.
- Fase recomendada: ideação, discovery, protótipo, MVP, GTM, operação ou escala.
- SWOT.
- PV/PUV.
- GTM.
- Arquitetura de dados e IA.
- Kanban.
- Roadmap 7/30/90 dias.

## Fontes de código

A primeira implementação analisa caminhos locais. GitHub com autenticação será implementado como adapter para clonar/listar repositórios com token do usuário ou integração OAuth.
