# Business Model Canvas no Product Management AI

O analisador gera uma hipótese de Business Model Canvas a partir de sinais do repositório: README, package metadata, dependências, nomes de arquivos, tags de arquitetura e documentação.

## Blocos gerados

- Customer Segments
- Value Propositions
- Channels
- Customer Relationships
- Revenue Streams
- Key Activities
- Key Resources
- Key Partners
- Cost Structure
- Key Metrics

## Importante

O canvas gerado é uma hipótese, não uma verdade. Ele deve ser validado com entrevistas, dados reais, contexto de mercado e estratégia do negócio.

## Uso recomendado

1. Rode `pm-ai analyze-repo`.
2. Abra o dashboard HTML.
3. Revise o Business Canvas com o founder, PM e engenharia.
4. Transforme lacunas em hipóteses.
5. Rode experimentos Lean para validar as hipóteses mais arriscadas.
