# Star-ready Roadmap

Este repositório foi organizado para virar um projeto open source forte, com potencial de ganhar muitas estrelas.

## Fundamentos de atração

- Quickstart em menos de 2 minutos.
- CLI com branding memorável.
- Python analyzer para gerar valor real em repositórios existentes.
- Dashboard visual sem dependências externas.
- Skills reutilizáveis por agentes e humanos.
- Templates práticos para PRD, MVP, canvas, roadmap e sprint.
- História do founder e posicionamento da Genial Labs AI.

## Próximas features de alto impacto

1. `pm-ai import-github <url>` para clonar e analisar repositórios públicos.
2. Exportação para Obsidian com notas interligadas.
3. Mapa C4 automático: Context, Container, Component e Code.
4. Score de maturidade de produto, tecnologia, dados e go-to-market.
5. Plugin visual com servidor local em Next.js ou Vite.
6. Integração com Codex/Claude Code para abrir issues automaticamente.
7. Comparação entre branches para explicar o impacto de produto de um PR.
8. Ranking de oportunidades por ICE/RICE e risco.
