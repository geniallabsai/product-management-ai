# Modelo operacional

Cadência semanal: revisar métricas, planejar sprint, executar delivery, rodar pesquisa, review, retrospectiva e atualizar decisões.

## Checklist prático

- Qual decisão precisa ser tomada?
- Quais evidências existem?
- Quais hipóteses ainda precisam ser testadas?
- Qual artefato será criado?
- Quem é dono do próximo passo?
