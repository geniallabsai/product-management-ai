# Como contribuir

## Princípios

1. Simplicidade antes de dependências.
2. Documentação clara para leigos e profundidade para PMs seniores.
3. Skills reutilizáveis fora do CLI.
4. Artefatos acionáveis, não apenas teoria.
5. Decisões explícitas, trade-offs visíveis e métricas claras.

## Checklist

- A mudança tem exemplo de uso.
- README ou docs foram atualizados.
- `npm test` passou.
- `npm run doctor` passou.
